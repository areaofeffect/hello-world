# Submitting your Week 2 homework with GitHub

We'll use GitHub to turn in homework from now on. GitHub is a website where programmers store and share code. This week you only need the website, no extra software.

You'll end up with a link that looks like `https://github.com/YOUR-USERNAME/hello-world-week2`. That link is what you submit in Canvas.

## What to put in your repo

| File | What it is |
|------|------------|
| `README.md` | Your name and one or two sentences about your story program |
| `data-types.md` | Assignment 1: four everyday objects represented as data types |
| `my-object.json` | Assignment 2: the object you checked at jsonlint.com |
| `story.py` | Assignment 3: your story algorithm |

You can name the files differently, but keep the file endings (`.md`, `.json`, `.py`). GitHub uses them to color your code.

## Step 1: Make a GitHub account

1. Go to [github.com](https://github.com) and click **Sign up**.
2. Use any email you check. A username that includes your real name makes it easier for us to find you.
3. Choose the free plan.

If you already have an account, sign in.

## Step 2: Create a repository

A repository (repo) is a folder that lives on GitHub.

1. Click the **+** in the top right corner, then **New repository**.
2. Repository name: `hello-world-week2`
3. Leave it set to **Public**.
4. Check the box **Add a README file**.
5. Click **Create repository**.

You now have a repo with one file in it, `README.md`.

## Step 3: Upload your homework files

1. On your repo page, click **Add file**, then **Upload files**.
2. Drag your files from your computer into the box, or click **choose your files**.
3. Scroll down to the **Commit changes** box. Type a short note about what you're adding, like `Add week 2 homework`. This note is called a commit message. Every change on GitHub gets one.
4. Click **Commit changes**.

Your files now appear in the list on your repo page. Click a file to see it. Python and JSON files show up with color coding, so we can read your code right in the browser.

Made a mistake? Fix the file on your computer and upload it again with the same name. GitHub replaces the old version and keeps the history.

## Step 4: Fill in the README

1. Click `README.md` in the file list, then click the pencil icon (Edit this file).
2. Delete what's there and write:
   - Your name
   - One or two sentences about your story program and how to run it (for example, `python3 story.py`)
3. Click **Commit changes**, then **Commit changes** again in the popup.

The README shows up on your repo's front page, so this is the first thing we see.

## Step 5: Submit the link in Canvas

1. Copy the URL from your browser's address bar while you're on your repo page. It should look like `https://github.com/YOUR-USERNAME/hello-world-week2`.
2. Open the Week 2 assignment in Canvas and click **Start Assignment**.
3. Paste the URL in the **Website URL** box and click **Submit Assignment**.

## Checklist before you submit

- [ ] Repo is public (you can open the link in a private or incognito browser window)
- [ ] `story.py`, `my-object.json` and `data-types.md` are all in the file list
- [ ] README has your name
- [ ] Link submitted in Canvas

## If you get stuck

- Uploading a folder: drag the whole folder into the upload box. It works in Chrome. Empty folders are skipped.
- "This repository is empty": you skipped the README checkbox. Click **Add file**, then **Upload files** anyway. It works the same.
- Wrong file uploaded: open the file, click the trash can icon, commit the change, then upload the right one.
- Anything else: bring your laptop to office hours or ask in class. Everyone gets tangled in GitHub the first time.

In a few weeks we'll install GitHub Desktop so you can do all of this without the website.
