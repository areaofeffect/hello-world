# Jitter

The classic p5 "Objects" example: a `Jitter` class, one object made from it, nudged around the screen every frame.

p5 removed this example from its website, so a copy lives here. The original source is in the [p5.js legacy website repo](https://github.com/processing/p5.js-website-legacy/blob/main/src/data/examples/en/11_Objects/01_Objects.js). The closest example on the current p5 site is [Shake Ball Bounce](https://p5js.org/examples/Classes-And-Objects-Shake-Ball-Bounce/).

Two versions, side by side:

- `sketch.js`: one bug, straight from the original example
- `jitterbugs.js`: 25 bugs in an array, each with its own color. Mouse over one to turn it red. Based on [Bruno's jitterbugs gist](https://gist.github.com/brunokruse/fcd85f3ec8c1da3f2b6759d152360611).

To run the jitterbugs version, change the script tag in `index.html` from `sketch.js` to `jitterbugs.js`.

Open `index.html` in a browser or with Live Server.
